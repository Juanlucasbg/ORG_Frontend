## Notes

- **LICENSE CLASS key**: PERMISSIVE = MIT / Apache-2.0 / BSD / Public Domain; COPYLEFT = GPL / LGPL / EPL; NONE = no license stated.
- `azac/cobol-on-wheelchair` is the most-starred pure COBOL web framework (1 000 stars, MIT).
- `meyfa/CobolCraft` is the flagship quirky project (694 stars, MIT) — a working Minecraft 1.21.4 server.
- `lauryndbrown/Cisp` (143 stars, MIT) stands out as a full language interpreter (Common Lisp) implemented entirely in COBOL.
- `cicsdev/cics-banking-sample-application-cbsa` is the most substantial banking demo but uses EPL-2.0 (copyleft).
- `IBM/cobol-is-fun` (archived) and `moxon6/cobol-js-emscripten` are notable IBM/community demos.
